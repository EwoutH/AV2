Quick start

Unpack the archive and run the tools from a terminal. The encoder reads .y4m video; FFmpeg can make one from almost any file.

ffmpeg -i input.mp4 -pix_fmt yuv420p -frames:v 30 input.y4m
avmenc input.y4m -o output.ivf --ivf --end-usage=q --qp=160 --cpu-used=6
avmdec output.ivf -o decoded.y4m
  • --qp sets quality: lower is better and larger. The AV2 test conditions use 110 to 235.
  • --cpu-used sets speed, 0 (slowest) to 9. AVM is research software and slow at any setting: expect seconds per frame, or minutes for HD.
  • On macOS, downloaded tools are blocked at first. Allow them with xattr -d com.apple.quarantine avmenc avmdec.

Good to know

  • These builds are unofficial and not from the Alliance for Open Media.
  • AV2 is still changing. A stream made with one build may not decode with another, so note the AVM commit in BUILD_INFO.txt.
  • TensorFlow Lite and the two encoder experiments that need it are turned off, so all platforms use the same encoder configuration.
